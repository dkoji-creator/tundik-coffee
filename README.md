# Tündik Coffee — demo landing page

A one-page website for a fictional coffee shop in Astana, made as a portfolio sample.

**Live:** https://dkoji-creator.github.io/tundik-coffee/

- Menu with tabs (coffee, tea, food) and prices in tenge
- Opening hours that highlight today
- Table booking form with name, phone and date validation (demo only, nothing is sent)
- Light and dark theme, works on phones

Plain HTML, CSS and JavaScript in one file, no frameworks.

The café, address and phone number are fictional.
